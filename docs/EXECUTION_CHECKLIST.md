# ✅ Execution Checklist — Wajib Diikuti AI Agent

> **Checklist ini WAJIB diikuti oleh AI Agent sebelum, saat, dan sesudah mengeksekusi skill.**

---

## Sebelum Eksekusi (PRE-FLIGHT)

```
□ Baca SKILL.md dari skill yang akan digunakan
□ Pahami konteks task dari user
□ Identifikasi dependency yang diperlukan
□ Pastikan environment sudah siap
□ Konfirmasi pemahaman dengan user (jika ada yang ambigu)
```

## Saat Eksekusi (DURING)

```
□ Ikuti langkah-langkah dalam SKILL.md secara berurutan
□ Jangan skip langkah apapun
□ Jalankan test di setiap milestone
□ Dokumentasikan apa yang dilakukan
□ Jika ada error, STOP dan perbaiki dulu
```

## Sesudah Eksekusi (POST-FLIGHT)

```
□ Jalankan semua test
□ Pastikan semua test passing
□ Verifikasi hasil sesuai spec
□ Update dokumentasi jika perlu
□ Catat hasil dan lessons learned
```

---

## Contoh Penggunaan

### Saat Membuat Landing Page

**Sebelum:**
```
□ Baca sources/taste-skill/skills/taste-skill/SKILL.md
□ Pahami: User mau landing page untuk SaaS
□ Identifikasi: Perlu design system, color palette
□ Siapkan: Project structure, dependencies
□ Konfirmasi: "Ini untuk SaaS B2B atau B2C?"
```

**Saat:**
```
□ Brief inference (Section 0)
□ Set design dials (Section 1)
□ Pilih design system (Section 2)
□ Implementasi layout (Section 3)
□ Tambah motion (Section 4)
□ Test di multiple device
```

**Sesudah:**
```
□ Test responsive di mobile, tablet, desktop
□ Pastikan tidak ada broken link
□ Verifikasi accessibility
□ Screenshot hasil
□ Present ke user
```

---

## Jika Ada Masalah

| Masalah | Aksi |
|---------|------|
| Test gagal | STOP, fix dulu, jangan lanjut |
| Tidak paham instruksi | Tanya user, jangan tebak |
| Ada error | Dokumentasikan, cari solusi |
| Waktu tidak cukup | Komunikasikan ke user, jangan skip |
| Tidak yakin | Verifikasi, jangan asumsi |

---

##larangan

```
❌ JANGAN skip test
❌ JANGAN tebak instruksi
❌ JANGAN asumsi tanpa bukti
❌ JANGAN "mengakali" aturan
❌ JANGAN selesai tanpa verifikasi
```
