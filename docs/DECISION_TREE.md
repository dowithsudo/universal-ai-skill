## Pertanyaan Lanjutan

### Jika Masih Bingung

```
Masih bingung?
│
├── Baca README.md → Panduan lengkap
├── Baca HOW_TO_USE.md → Panduan praktis
├── Baca QUICK_REFERENCE.md → Kartu singkat
└── Tanya user → Klarifikasi kebutuhan
```

### Jika Skill Tidak Ada

```
Skill tidak ada?
│
├── Cek registry/skill_index.json → Cari manual
├── Cek semua folder sources/ → Browse semua skill
└── Buat skill baru → Gunakan template di SKILL_TEMPLATES.md
```

---

## Tips

1. **Mulai dari pertanyaan utama** — "Mau buat apa?"
2. **Ikuti pohon ke bawah** — Ikuti cabang yang sesuai
3. **Jika bingung, tanya** — Lebih baik tanya daripada tebak
4. **Jika tidak ada, buat** — Gunakan skill template

---

**Gunakan pohon keputusan ini saat tidak tahu skill mana yang dipakai.**
