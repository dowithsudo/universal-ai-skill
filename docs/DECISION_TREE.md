## 💡 Tips Memilih

### 1. Mulai dari Hasil yang Diinginkan
> "Saya mau landing page yang terlihat mahal" → `soft-skill`

### 2. Perhatikan Difficulty Level
> Jika baru pertama kali, mulai dari `beginner` skills

### 3. Gunakan Combo untuk Proyek Besar
> Kombinasikan beberapa skills untuk hasil optimal

### 4. Cek Related Skills
> Setiap skill memiliki "related_skills" untuk eksplorasi lebih lanjut

### 5. Gunakan Preview Tool
```bash
# Lihat preview skill sebelum dipakai
./scripts/preview_skill.sh taste-skill
```
